Take it for a sweep.

This is the extension's own code running against a hand-written stand-in for Gmail. No account, no real email, nothing leaves this page.

mail.google.com/mail/u/0/#sub (stand-in)

What to do

  1. Look at the stand-in list: five senders, one of which only offers Go to website.
  2. Press Start sweep in the popup.
  3. Watch each dialog open and get confirmed, one sender at a time, bottom row first.
  4. The popup should end on Swept: 4 unsubscribed, 1 skipped. Example Travel stays, because it has no one-click option.
  5. Press Reset and try again with the website box ticked. The click is counted; in the demo it opens nothing.

On a phone? It works, but the demo is easier on a wider screen. Open the demo on its own.

This is a stand-in, not Gmail, so it shows how the loop behaves, not proof that it works on your account.
