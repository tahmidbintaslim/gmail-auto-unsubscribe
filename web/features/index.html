One button. A lot of restraint.

The free extension does a single job: it works down Gmail's Manage subscriptions list and says no to everything you didn't ask for. Here is all of it.

It confirms the one-click ones

For each sender, from the bottom row up, UnsubSweep clicks the row's Unsubscribe, then the Unsubscribe in Gmail's dialog. It only confirms a dialog it just opened itself, and each sender gets one try per run.

It waits about a second between senders, so a long list takes a few minutes. Plenty of time for that kettle.

A website fallback, on a short leash

Some senders don't offer one-click unsubscribe, only a link to their site. By default UnsubSweep clicks Cancel and counts them as skipped.

Tick the box in the popup and it clicks Go to website instead, which opens the sender's own page in a new tab for you to finish. Never more than five tabs per run.

It knows when to stop

A run ends the moment anything looks off. It never guesses, and it never clicks an Unsubscribe link inside a message: it checks the address before every click.

  • Every sender on the list has had its turn
  • You press Stop
  • The tab leaves Manage subscriptions
  • 250 senders in one run (press Start to carry on)
  • A Gmail dialog won't close

Counts you can watch

The popup shows unsubscribed, skipped and websites opened as the run goes. Close it whenever you like; the run carries on in the Gmail tab, and reopening the popup shows where it got to.

Two permissions, no install warning

No host permissions and no content scripts in the manifest, so Chrome shows no site-access warning. Nothing runs in Gmail until you press Start, and only in the tab you opened the popup from.
