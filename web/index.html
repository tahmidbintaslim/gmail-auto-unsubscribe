Stop unsubscribing one by one

Gmail makes you leave each sender separately: click Unsubscribe, wait for the box, confirm, repeat. UnsubSweep does that same clicking for you, down the whole list.

  1. Open Manage subscriptions

    It's in Gmail's left menu, sometimes under More.

  2. Press Start sweep

    Click the UnsubSweep icon in Chrome, then the button.

  3. Watch the list clear

    About one sender a second. Stop whenever you like.

One click clears the whole list

Open Gmail's Manage subscriptions page and press Start sweep. It unsubscribes from each sender, about one a second.

It goes through every sender on the page, and there's no undo.

Does it read my email?

No. It only sees the Manage subscriptions page while it runs: the sender names and the buttons. It can't open messages.

Can I choose which senders to keep?

Not yet. A run unsubscribes from every sender on the page, and it can't be undone. Only press Start when you want to leave them all.

Do I need an account or to pay?

No account, no sign-in and no payment. Install it and press Start.

Does it work in my language?

Only when Gmail is set to English for now. In other languages it finds nothing to click.

Has it been tested on real Gmail?

It's tested on a copy of Gmail's page that we wrote by hand, not yet on a live account. Gmail can change its page at any time.
