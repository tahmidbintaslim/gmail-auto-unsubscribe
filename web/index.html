Ready

Three steps, and the third is a cup of tea

  1. Open Manage subscriptions

    It is in Gmail's left menu, sometimes tucked under More. That list is the only place UnsubSweep will work.

  2. Press Start sweep

    Clicking the icon lends it that one tab, for now. Nothing runs in Gmail until you press the button.

  3. Put the kettle on

    It confirms each one-click Unsubscribe, about a second apiece, from the bottom row up. A sender without one is skipped, or sent to its own website if you allow it.

No undo, no keep-list yet. A run goes through every sender on the page, so press Start when you mean it. Want to watch first? Run the real code in the demo.

Your inbox stays your business.

Most unsubscribe tools want to read your mail on their servers. UnsubSweep doesn't have a server to read it on.

  • No Gmail API, no OAuth, no tokens. Nothing shows up under third-party access in your Google account, because nothing asked.
  • No network requests of its own. Gmail sends the unsubscribe requests, exactly as if you had clicked. Go to website, if you turn it on, opens the sender's own site in a new tab.
  • Nothing stored. Counts live in memory and vanish with the tab. No storage, no remote code, no analytics.
  • Read every line. Four small files on GitHub. Then read the privacy policy, which is short for a reason.

Fair questions.

Does it read my email?

No. On the Manage subscriptions page it reads button labels, the text of sender rows and the tab's address. It never opens a message.

Has it been tested on real Gmail?

Not yet. It is tested against a hand-written stand-in for Gmail's page. A check on a live account is the next job, and the docs list the steps if you want to try it yourself.

Can I keep some senders?

Not in this version. A run goes through every sender on the page. A preview and keep-list are on the roadmap.

My Gmail is in another language.

Then it finds nothing to click. It matches Gmail's English labels for now.

Is the AI part real?

Not yet. Recommendations, categories, rules and the digest are in development. Nothing AI ships today, and the free sweep never needs it.

Where's the Chrome Web Store link?

The listing is being prepared. Until then, install it with Load unpacked. The docs walk you through it in five steps.
