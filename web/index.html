Questions people ask

Does it read my email?

No. It only sees the Manage subscriptions page while it runs: the sender names and the buttons. It can't open messages.

Can I choose which senders to keep?

Not yet. A run unsubscribes from every sender on the page, and it can't be undone. Only press Start when you want to leave them all.

Do I need an account?

No account, no sign-in and no payment. Install it and press Start.

Does it work in my language?

Only when Gmail is set to English for now. In other languages it finds nothing to click.

Has it been tested on real Gmail?

It's tested on a copy of Gmail's page that we wrote by hand, not yet on a live account. Gmail can change its page at any time.

Where is the Chrome Web Store link?

Coming. Until then you can install it from GitHub in about a minute.
