# UX Copy Review: Website Home Page

Reader: an everyday Gmail user, mildly annoyed by newsletters, cautious about giving anything access to email. Tone: plain, friendly, reassuring.

## Recommended copy (applied)

| Element | Before | Now | Why |
|---|---|---|---|
| Headline | Bulk unsubscribe from Gmail. Without giving anyone your inbox. | Unsubscribe from every newsletter in one click | Says the outcome first, in the reader's words. "Bulk" is jargon. |
| Sub-headline | UnsubSweep presses Unsubscribe on Gmail's own Manage subscriptions page, sender after sender… | UnsubSweep clears your Gmail subscriptions for you. It's free, and it never reads your email. | One sentence: what, price, safety. |
| Primary button | Install free from GitHub / Get UnsubSweep | Install UnsubSweep free | Starts with a verb, names the outcome, says it's free. "GitHub" means nothing to this reader. |
| Header button | Get it free | Install free | Same verb as the main button. |
| Under the button | Open source. Two permissions. The Chrome Web Store listing is on its way. | For Chrome on a computer. Takes about a minute to install. | Sets expectations: device and effort. |
| Steps heading | Three steps. The third is a cup of tea. | Three steps, about a minute | Tells the reader the effort, no joke to decode. |
| Trust heading | Your inbox stays your business. | Built to be trusted with your inbox | Direct. |
| Closing line | Free, open source, and it never asks for your password. | Free. No sign-in. Takes about a minute. | The three facts that remove hesitation. |

## Alternatives for the headline

| Option | Copy | Tone | Best for |
|---|---|---|---|
| A (used) | Unsubscribe from every newsletter in one click | Plain | Search and store visitors |
| B | Clear out your Gmail subscriptions in one click | Plain | If "newsletter" tests too narrow |
| C | One click. Every newsletter gone. | Punchy | Ads and social cards |

## Warnings and limits

- "It goes through every sender on the page, and there's no undo." sits directly under the main benefit.
- "Not yet. A run unsubscribes from every sender on the page…" answers "Can I choose which senders to keep?".
- Pro is always "In development", never "coming soon".

## Extension popup (already shipped)

| State | Copy |
|---|---|
| Wrong site | Open Gmail first. |
| Wrong page | Open Gmail's Manage subscriptions page first. |
| Running | Running: 3 unsubscribed, 0 skipped. |
| Finished | Swept: 4 unsubscribed, 1 skipped. |
| Can't run | Could not run on this tab. Reload Gmail and try again. |

Each error says what happened and what to do next.

## Localization notes

- "Sweep" and "Swept" are English wordplay; translate as "clear" and "cleared".
- Gmail's page name "Manage subscriptions" must match the reader's Gmail language.
- Allow 30% extra width for buttons in German and French.
